# cs430-final-group--group1-
An e-commerce store for designer watches from all over. From different brands

Our teammate Keneth Vargas came up with the idea for an e-com store for luxury watches.


Project Title; KinG Watches

Brief Description: An E-commerce store for luxury and quality watches, for an affordable price.

Team Memebers and Roles: Kinza Maqsood set up the html elements.

I, Gabriella Gonzalez, did the stylization of all HTML files.

Kenneth worked on JavaScript and technicalities.

Technologies used:
VSCode, GitHub, GitHub pages,

Key features:
1. Interactive E-Commerce Experience:
Users can browse watches from across multiple pages
Products are rendered, not hardcoded HTML
Product details/description open in a modal
2.Full Functional Cart System:
Add items from homepage and product modal
Increase and decrease quantity
remove items
cart persists even after a page refresh
and there is a live total cart calculation
3. Product Filtering System:
Filters by categories
-Sporty
-Timeless
-Modern
-Old Fashioned
Updates without a page reload
Visual Feedback with active button states
4. Multimedia Integration:
Images (product and models)
Video (hero section on the main page)
Audio:
Add to cart "ding" feedback
Contact form voice response.
5. Javascript-Driven UI Logic:
Modular systems including CartManager, ModalManager, and CartUI.
Event handling across pages
Data Normalization (normalizeProduct)
6. Simulated Checkout 
User inputs:
-Address
-Cardo Info (mock)
-validates cart before purchase
clears the cart after checkout
displays a confirmation message
7. Responsive Design:
From CSS:
-Grid layouts (auto-fit)
-mobile adjustments with media queries
Flexible layouts (hero + product grid)
8. Luxury UI Styling
-Dark themes with gold accents
-card hover effects
-clean typography  hierarchy
-styled buttons and modals
9. Accessibility Considerations
-alt text for images
-ARIA roles for modal (role="dialog)
-Keyboard close
10. Modualr Code Structure:
-CartManager --> data logic
-CartUI --> display logic
-ModalManager --> product interactions
